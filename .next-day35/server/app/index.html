Questions, answered

Clear answers before you start.

AI can make mistakes. Your recovery plan should be based on links you can verify.

Can Citemend stop AI from hallucinating links?

No tool can control every AI answer. Citemend checks URLs found in a search-backed citation audit. When one returns 404, it suggests a verified live page so you can recover the visit with a redirect.

Is the free preview a full AI citation audit?

No. The no-sign-in preview checks homepage and default sitemap availability. Sign in to run one free saved AI citation audit for your account; Pro unlocks additional audits and redirect tools.

Will redirects go live without my approval?

No. Suggestions are reviewable first. A Pro user must publish a rule, and the Cloudflare Worker must be connected to that domain before it can handle traffic.

What if a cited page is only temporarily down?

A failed network check is not counted as a confirmed 404. Review every suggested redirect before publishing it, especially if a page may return later.
